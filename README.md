Socket Programming: Simple Web Server
This activity demonstrates socket programming in Python by creating a simple web server that handles HTTP requests from a web browser. 
The server uses Python's socket library to listen for client connections and threading to handle multiple requests.

Requirements:
Python 3
A web browser
Image, video, and audio files stored in the media directory.

How:
Save the Python code as server.py.
Place the multimedia files in the appropriate directory:
media/sample_image.jpg
media/sample_video.mp4
media/sample_audio.mp3
